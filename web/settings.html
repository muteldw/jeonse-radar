저장하기

  1. 설정 복사를 누릅니다.
  2. GitHub에서 열기 → 연필(편집) 화면에서 내용을 모두 지우고 붙여넣습니다.
  3. 오른쪽 위 Commit changes를 누르면 다음 정각부터 적용됩니다.
GitHub에서 열기 지금 시험 발송

'지금 시험 발송'은 Actions 화면에서 Run workflow를 누르면 켜진 대상 모두에게 바로 보냅니다.
